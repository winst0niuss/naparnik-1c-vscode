# Изменения

## 0.7.5

- Исправлено: команда с `@end` в той же строке («@read_file a.md @end») больше не ломает путь — из-за этого `/init` на проектах из нескольких папок шёл 20+ раундов.
- Документация подпроектов (README, CLAUDE.md… в папках первого уровня) находится и передаётся модели.
- Разрешён серверный инструмент плана задач `TodoWrite` — раньше его отклонения упирались в лимит раундов («Превышен лимит шагов поиска»).
- `/init` на больших проектах: небольшой проект показывается целиком, большой — до 4 уровней с «… ещё N» в больших папках (видны все папки верхнего уровня), `@list_dir папка | глубина`, `@read_file` на папке показывает её содержимое.
- Скрывается только то, что игнорирует git: пути из `.gitignore` (во всех папках, каждый относительно своей) и папка `.git` не показываются в структуре проекта и не участвуют в поиске. Встроенные списки папок и фильтр «секретных» файлов убраны — расширение не решает за проект, что скрывать.
- Лимит шагов: вместо ошибки модель получает указание завершить задачу по собранному; для `/init` и `/make-rules` — 25 шагов.
- Если модель вместо команд пишет «читаю…» или `/init` не создал NAPARNIK.md — ей напоминают продолжить.
- Исправлено: ошибки TypeScript в редакторе VS Code (TypeScript 6) — типы Node.js подключены явно.

## 0.6.5

- Карточка правки показывается только в чате, где правку предложили: Enter в другом чате не применит чужую правку.
- Шаги работы с проектом («Смотрю…», «Читаю…») сворачиваются в одну строку: во время работы — последний шаг и счётчик, после ответа — сводка «Просмотрено: 36 папок, 4 файла». Клик разворачивает список.
- Статус записи файла: «Пишет NAPARNIK.md · 3 348 символов» — без сокращений.
- Правку можно подтвердить клавиатурой: Enter — применить, Esc — отклонить (в чате и во вкладке diff); diff больше не забирает фокус у чата.
- Убраны дублирующие уведомления о правках — подтверждение в карточке чата или кнопками в заголовке diff.
- Контекст редактора: открытый файл или выделенный фрагмент автоматически прикладывается к сообщению вместе с ошибками VS Code. Чип над полем ввода показывает, что будет приложено; клик — не прикладывать.
- «Спросить Напарника о выделенном коде» прикладывает выделение как контекст — с путём к файлу и номерами строк.
- Неизменённый файл повторно в тот же чат не отправляется.

## 0.5.2

- Слэш-команды: меню при вводе «/», `/init`, `/rules`, `/make-rules`, `/clear`, `/history`, `/project`, `/stop`, `/token`, `/help`, `/exit`.
- `/init` создаёт NAPARNIK.md — описание проекта, которое подставляется в каждый новый чат.
- Напарник сначала читает документацию и инструкции ИИ-инструментов (README, CLAUDE.md, AGENTS.md, GEMINI.md, правила Cursor/Copilot/Windsurf).
- Правила проекта в папке .rules: «запомни…» записывает правило, `/make-rules` собирает правила из чата.
- Статус «Пишет файл… N симв.» и отдельный секундомер для каждого этапа.
- Таймаут считается по паузе в данных (по умолчанию 300 с), длинные ответы не обрываются.

## 0.4.6

- Доступ к проекту: кнопка «Доступ к проекту» в чате. Напарник смотрит структуру, читает и ищет файлы.
- Правки файлов: предложенное изменение открывается как diff и применяется после подтверждения — кнопками в чате или в заголовке diff.
- Шаги работы («Читаю …», «Ищу …») видны в чате и сохраняются в истории.
- Создание файлов командой Напарника (с подтверждением).
- Анимированный статус «Напарник думает» с секундомером.
- Вкладка и заголовок панели — «Напарник».
- Безопасность: файлы с секретами (.env, ключи) не читаются; символические ссылки не выводят за пределы проекта; правка не применяется, если файл изменился во время просмотра diff.
- Инструменты 1С:EDT, недоступные вне EDT, отклоняются — Напарник переключается на команды расширения.
